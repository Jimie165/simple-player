# 常见问题诊断 (Troubleshooting)

本文档汇总了 Simple Player 使用过程中可能遇到的常见问题及解决方案。

## 1. 媒体扫描问题

### 扫描卡住或遗漏文件
- **检查**: 确认文件路径是否包含特殊字符或系统权限受限的目录。
- **原因**: 部分音频文件元数据编码（如 GBK）可能导致解析失败。
- **解决**: 尝试重新扫描或检查控制台日志 (Ctrl+Shift+I) 查看具体报错文件。

### 视频无法被扫描
- **检查**: 确认视频文件格式是否为常见格式 (mp4, mkv, avi, mov)。
- **原因**: 默认过滤器仅包含主流视频扩展名。

## 2. 播放与转码

### 视频播放失败或黑屏
- **检查**: 确认系统是否安装了必要的解码器。
- **解决**:
  1. 确保已安装 FFmpeg 并在系统环境变量中。
  2. 在设置中检查“硬件加速”状态，尝试切换或关闭硬件加速。
- **提示**: 本应用依赖浏览器能力进行播放，不兼容的编码（如部分 HEVC）需要转码后播放。

### 转码速度慢
- **解决**: 开启硬件加速 (NVENC/QSV)。如果显卡不支持，将回退到软件编码（较慢）。

## 3. 界面与交互

### 新建播放列表无反应
- **检查**: 确认是否已升级到最新版本，旧版本可能存在弹窗层级问题。

### 快捷键无效
- **原因**: 部分全局快捷键可能被其他软件占用。
- **解决**: 确保应用窗口处于激活状态（对于非全局快捷键）。

## 4. 开发相关

### `pnpm dev` 启动失败
- **错误**: `failed to run cargo build`
- **解决**:
  1. 确认 Rust 环境正常 (`rustc --version`)。
  2. 确认 Tauri 依赖（如 WebView2）已安装。
  3. 尝试删除 `backend/target` 目录后重试。

---

如果问题仍未解决，请将详细日志和复现步骤提交给开发者。
